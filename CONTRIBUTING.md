# Contributing

1. Fork the repository and create a focused feature branch.
2. Keep hardware, pinout, command protocol, and safety documentation synchronized with code changes.
3. Compile the sketch in Arduino IDE before opening a pull request.
4. Test on a raised chassis or wheel stand first; never test autonomous motion near people, pets, stairs, or fragile objects.
5. Describe board revisions, library versions, and test conditions in the pull request.
